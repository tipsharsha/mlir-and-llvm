1. Purpose

This manual gives a program of study for LLVM and MLIR. The program prepares you for the sessions about the Modular stack.

The Modular stack contains Mojo and MAX. Both use MLIR. The code then goes through LLVM to the CPU or the GPU.

2. Scope

This issue contains Week 0 and Week 1. Later revisions will add Week 2 to Week 13.

3. How to use this manual

  • Do the tasks in the sequence that this manual gives.
  • Do all the steps of a task before you start the next task.
  • Use the tabs on the left. Each week has one tab, and each tab has chapters.
  • When you complete a step, select its box. The app keeps the record.
  • Do the check at the end of each week. If an answer is incorrect, do the related task again.

5. Language standard

This manual uses the rules of ASD-STE100 Simplified Technical English. Each step gives one instruction. Procedural sentences have a maximum of 20 words. Descriptive sentences have a maximum of 25 words.
