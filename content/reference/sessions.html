2. Seven more questions from the series

  1. Part 7: Triton is an eDSL, and an eDSL “looks like Python but is not Python”. Is Mojo a real language or an eDSL? How does it avoid this problem?
  2. Part 8: Did Modular keep the upstream dialects arith, linalg and tensor? Or did it define its own?
  3. Part 6: What is the unit of fusion in MAX? Does it use auto-tuning, and how does it keep compile times short?
  4. Part 9: How does Modular avoid “chasing the whale” when a large customer asks for a custom feature?
  5. Part 11: What does a hardware vendor write to add a new accelerator? What does Modular write?
  6. Parts 4 and 10: How does Modular handle changes between NVIDIA generations, for example Hopper to Blackwell?
  7. Part 10: Which parts are open source now, and which are not? What happens to the closed parts?

3. Claims to check

  • “One binary” runs on NVIDIA GPUs, AMD GPUs and CPUs (Part 11). Ask for the conditions.
  • Top speed on Hopper and Blackwell (Part 11). Ask for the benchmark, the model and the baseline.
  • The size of the open-source code: over half a million lines (Part 10), hundreds of thousands (Part 11).
  • The checklist of twelve items is a self-assessment. Ask which items are not yet met.
