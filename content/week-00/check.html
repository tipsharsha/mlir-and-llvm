Table 0-8 · Week 0 questions

Q1What are the three phases of a classic compiler?
The front end, the optimizer and the back end. The front end reads the source code and makes an IR. The optimizer improves the IR. The back end makes machine code for one target.
Q2A shared IR connects N languages to M targets. How many front ends and back ends are necessary?
N front ends and M back ends. Without a shared IR, you can need N × M different compilers.
Q3In Part 2 of R1, the word “CUDA” refers to more than one thing. Give three of them.
For example: the parallel programming model and its language (CUDA C++). The software platform: the compiler, the libraries (for example cuBLAS and cuDNN) and the tools. The ecosystem and the brand around them.
Q4Why was MLIR made?
Many AI frameworks and hardware companies made their own compilers and IRs. They did the same work many times. MLIR gives one shared infrastructure for many IRs. These IRs are the dialects.
Q5Which file sets the memory limit of WSL2? Which command shows the memory in Ubuntu?
The file %UserProfile%\.wslconfig sets the limit. The command free -g shows the memory.
Q6Which LLVM major version did apt install?
On Ubuntu 24.04, it is LLVM 18. Your result is in step (5) of TASK 00-20-00-400-802.
