TASK 00-20-00-200-801Examine the WSL2 installation5 min

1. General

This task makes sure that Ubuntu operates on WSL2. The tools in this program need WSL2. WSL1 is not satisfactory.

2. Job set-up information

Tools and equipmentReferenced information
Windows PowerShellR5

3. Procedure

  1. (1)
    Open Windows PowerShell.
  2. (2)
    Show the WSL distributions: 
    wsl -l -v
  3. (3)
    Make sure that the line for Ubuntu shows 2 in the VERSION column.
  4. (4)
    Start Ubuntu: 
    wsl -d Ubuntu
  5. (5)
    Show the Ubuntu release: 
    lsb_release -ds
  6. (6)
    Make sure that the release is Ubuntu 24.04 or later.
NOTE:At the date of this issue, the result was Ubuntu 24.04.3 LTS on WSL2. The docker-desktop line is for Docker Desktop. This program does not use it.
TASK 00-20-00-400-801Increase the WSL2 memory limit15 min

1. General

By default, WSL2 can use 50 percent of the computer memory. On your computer, this is approximately 11 GB.

The MLIR build in Week 4 needs more memory. This task sets the limit to 16 GB. It also adds 16 GB of swap space.

WARNING

DO NOT SET THE MEMORY LIMIT TO MORE THAN 18 GB. Windows must keep approximately 6 GB. If Windows has less memory, applications can stop.

NOTE:This limit also applies to Docker Desktop, because Docker Desktop uses WSL2.

2. Job set-up information

Tools and equipmentReferenced information
Windows PowerShell, NotepadR5

3. Procedure

  1. (1)
    Open the file .wslconfig in Notepad: 
    notepad "$env:USERPROFILE\.wslconfig"
  2. (2)
    If Notepad asks to make a new file, select Yes.
  3. (3)
    Write these lines in the file: 
    [wsl2]
memory=16GB
swap=16GB
  4. (4)
    Save the file.
  5. (5)
    Close Notepad.
  6. (6)
    Stop WSL: 
    wsl --shutdown
  7. (7)
    Start Ubuntu: 
    wsl -d Ubuntu
  8. (8)
    Show the memory: 
    free -g
  9. (9)
    Make sure that the total value in the Mem line is 15 or more.
  10. (10)
    Make sure that the total value in the Swap line is 15 or more.
TASK 00-20-00-400-802Install the compiler tools20 min

1. General

This task installs Clang, LLVM and the build tools from the Ubuntu packages. Ubuntu 24.04 supplies LLVM 18.

Week 4 builds a newer LLVM and MLIR from the source code. LLVM 18 is satisfactory for Weeks 1 to 3.

CAUTION

KEEP ALL WORK FILES IN THE LINUX FILE SYSTEM, FOR EXAMPLE IN ~/lab. DO NOT KEEP WORK FILES IN /mnt/c. File operations in /mnt/c are much slower.

2. Job set-up information

Tools and equipmentReferenced information
Ubuntu shell in WSL2, internet connection, your Ubuntu password (for sudo)—
Packages that this task installs
PackageContents
build-essentialGCC, make and the C library headers.
clang, lldThe Clang C and C++ compiler. The LLVM linker.
clangdThe language server for editors. It shows errors and completes names.
llvmopt, llc and the other LLVM tools.
llvm-devThe LLVM headers and llvm-config. Week 2 uses them.
libclang-rt-18-devThe sanitizer run-time libraries for Clang.
cmake, ninja-buildThe build tools that LLVM and MLIR use.
graphvizThe dot command. It makes drawings of control flow graphs.

3. Procedure

  1. (1)
    Start Ubuntu.
  2. (2)
    Update the package index: 
    sudo apt update
  3. (3)
    Install the packages: 
    sudo apt install -y build-essential clang clangd lld llvm llvm-dev libclang-rt-18-dev cmake ninja-build graphviz
  4. (4)
    Show the tool versions: 
    clang --version
opt --version
llvm-config --version
  5. (5)
    Make sure that the three tools show the same major version. Record the version.
  6. (6)
    Make the work directory for Week 1: 
    mkdir -p ~/lab/week-01
NOTE:VS Code with the WSL extension can edit the files in WSL. In Ubuntu, the command code . opens the current directory. The clangd extension uses clangd.
TASK 00-20-00-400-803Install Mojo (installation check)20 min

1. General

Weeks 7 to 12 use Mojo. This task makes sure now that Mojo installs and operates in WSL2. Thus, the Mojo weeks can start without delay.

NOTE:The install procedure can change. At the date of this issue, the steps in this task agree with R3. If R3 and this task are different, R3 is correct.

2. Job set-up information

Tools and equipmentReferenced information
Ubuntu shell in WSL2, internet connectionR3, R4

3. Procedure

  1. (1)
    Install the pixi package manager: 
    curl -fsSL https://pixi.sh/install.sh | sh
  2. (2)
    Load the new PATH: 
    source ~/.bashrc
  3. (3)
    Go to the lab directory: 
    cd ~/lab
  4. (4)
    Make a Mojo project: 
    pixi init mojo-check -c https://conda.modular.com/max/ -c conda-forge
  5. (5)
    Go to the project directory: 
    cd mojo-check
  6. (6)
    Add the Mojo package: 
    pixi add mojo
  7. (7)
    Show the Mojo version: 
    pixi run mojo --version
  8. (8)
    Make sure that the command shows a version number.
  9. (9)
    Make the file hello.mojo: 
    cat > hello.mojo <<'EOF'
def main():
    print("Hello from Mojo")
EOF
  10. (10)
    Run the program: 
    pixi run mojo hello.mojo
  11. (11)
    Make sure that the output is Hello from Mojo.
NOTE:This task does not use the GPU. Week 10 examines the GPU in WSL2.
