Week 1 has two parts. Section 01-10-00 refreshes the C++ that the LLVM tutorials use. Section 01-20-00 shows LLVM IR with the command-line tools.

Section 01-20-00 does not need C++. It uses small C programs.

Objectives

At the end of Week 1, you can do these items:

  • Read and write a small C++ class hierarchy that uses std::unique_ptr.
  • Build a C++ program with CMake and Ninja.
  • Read LLVM IR. Find the functions, basic blocks, instructions and phi nodes.
  • Use opt to apply one pass and the full -O2 pipeline.
  • Find a vectorized loop in optimized LLVM IR. Explain why a floating-point loop does not vectorize.

The total time is approximately 7 hours. The record sheet in 01-90-00 gives the time for each task.

NOTE:Week 2 starts the Kaleidoscope tutorial (R15). Kaleidoscope uses the C++ of Section 01-10-00 and the same class names.
