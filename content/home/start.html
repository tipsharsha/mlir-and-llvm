TRAINING PROGRAM

MLIR and LLVM for the Modular Stack

Preparation for the Chris Lattner sessions about Mojo and MAX

THIS ISSUE CONTAINS: the program introduction and schedule, Week 0 (set-up and background study) and Week 1 (C++ refresher and LLVM IR).

LANGUAGE STANDARD: ASD-STE100 Simplified Technical English.

How this app works

  • Each week has a tab on the left. Select a tab to see its chapters.
  • A chapter has tasks, reading cards and self-tests.
  • When you complete a step, select its box. When you have read a reading card, select its box.
  • The app saves your progress. Select Continue to go back to your place.

Where to start

  1. Read the Introduction and the Program schedule.
  2. Do Week 0, Computer set-up.
  3. Read the Week 0 background chapters. They contain a digest of each source, so you do not need to search.
  4. Do Week 1. It starts with a C++ refresher.
